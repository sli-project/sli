# Установка сервера

[English version](SERVER_INSTALL.en.md)

На Debian 13 amd64 начните со скачивания `sli-debian-beta-kit.tar.gz` и
`SHA256SUMS` из одного выпуска `beta-…` в разделе [Releases](https://github.com/sli-project/sli/releases).
По README [проверьте и установите архив](../../README.ru.md#установка-из-архива),
затем [войдите в SLI](../../README.ru.md#первый-вход).

В README также описаны
[необязательные параметры](../../README.ru.md#необязательные-параметры-установки),
[обновление](../../README.ru.md#обновление) и
[переустановка с сохранением данных](../../README.ru.md#переустановка-с-сохранением-данных).
