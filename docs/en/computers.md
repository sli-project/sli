# Computers

[Русская версия](../ru/computers.md) · [Work screens](user-guide.md)

Open **Computers** at `/app/report/ad.computers.v6`. Select the domain and
search for the computer or review the available checks.

1. Open a computer to see directory and observation details. Check the
   computer type and observation time before comparing activity from different
   sources.
2. Use **Changes** or **Compare snapshots** in the card when offered to
   review stored before and after observations. For rights and source events,
   use the available links to the AD object or [Event journal](event-journal.md).
3. Use **Computer logons** at `/app/report/ad.computer-logons` or the **Logons**
   tab of an eligible workstation. Select the period and inspect individual
   logon observations. A source-event link appears when that record is
   available. The view depends on workstation observations and report access.
