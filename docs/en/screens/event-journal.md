# Event journal

[Русская версия](../../ru/screens/event-journal.md) · [Work screens](../user-guide.md)

Open **Event journal** at `/app/report/events.journal` to find and verify
individual collected events.

1. Choose a period and domain as available. Select a category such as
   **Logons**, **Accounts**, **Groups and rights** or **Audit**. Search by
   account, computer, address or event. Review the event time, code and log,
   then check the result.
2. Use **Collapse repeats** for a compact view. Expand a repeated entry to
   review individual source events when they are available. Use a link on
   an account, address or computer to narrow the investigation.
3. Open a row for **Details** and **Source event**. Check the source, log and
   record number before relying on an event ID. Go to the full event card
   for retained evidence when your access permits it.
4. If you came from [Problems](problems.md), check the selected finding and
   period. Source payload and event summaries can have different retention
   periods.
