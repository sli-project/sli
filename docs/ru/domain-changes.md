# Изменения в домене

[English version](../en/domain-changes.md) · [Рабочие экраны](user-guide.md)

Откройте **Изменения в домене** по пути `/app/report/security.events.chains`,
чтобы разобрать изменения, зафиксированные в доменных событиях.

1. Выберите период и домен, затем вид, например **Учётные записи**,
   **Группы**, **Пароли** или **Аудит**. Ищите по объекту, инициатору или
   атрибуту. При необходимости отберите записи по операции.
2. Откройте изменение, сопоставьте объект, поле или группу с операцией,
   инициатором, контроллером домена и временем. Если повторы свёрнуты,
   разверните группу для просмотра строк.
3. В деталях откройте **Участники** и **Исходное событие**. При наличии
   ссылок ограничьте выдачу участником или откройте полную карточку
   события. Выгружайте CSV, если действие доступно и ваш порядок работы
   допускает выгрузку этих записей.

Различия собранных снимков каталога смотрите в [Состоянии AD](ad-state.md).
Для поиска событий по коду и источнику используйте
[Журнал событий](event-journal.md).
