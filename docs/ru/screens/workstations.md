# Рабочие станции

Раздел предназначен для разбора событий зарегистрированных рабочих станций.
Основной маршрут — `/app/report/workstations.overview`; адрес `/app/workstations`
сохраняется как совместимый переход с теми же параметрами.

## Порядок работы

1. Выберите домен, найдите станцию и при необходимости ограничьте состояние
   назначения сбора. Список поддерживает страницы по 25, 50, 100 и 200 строк.
2. Откройте станцию. Её события и сведения о сборе занимают основную область
   страницы. Кнопка «К списку» возвращает исходную выборку и страницу.
3. Задайте период и тип событий. Начальная и конечная границы относятся к
   событиям; сведения о станции показывают время обновления записи инвентаризации.
4. Откройте подробности записи или связанный журнал. Переход сохраняет источник
   станции и период. Доступность исходного доказательства и проблемы проверяется
   отдельно от права просматривать список станций.
   Карточка исходного события содержит кнопку возврата к отчёту. Дополнительные
   связанные факты и оценки открываются отдельной кнопкой по необходимости.

## Что означает информация на экране

| Информация | Значение |
|---|---|
| Станция, домен и ОС | Данные зарегистрированного агента и подтверждённой привязки источника; неизвестные значения не дополняются по похожему имени |
| Последняя связь | Сохранённая отметка контакта агента; сама по себе не доказывает, что компьютер сейчас включён |
| Сведения обновлены | Время обновления записи инвентаризации; не время отдельного измерения каждого её свойства |
| Ревизия политики | Назначенная и подтверждённая агентом версии; различие показывает, что новая версия ещё не подтверждена |
| Состояние сбора | Состояние назначения и привязки источника, отдельно от наличия событий за выбранное время |
| Запись журнала | Сохранённое событие или сохранённая группа наблюдений |
| Число в группе | Количество наблюдений, а не число компьютеров, файлов или доступных исходных XML |
| Критичность | Тяжесть связанной опубликованной проблемы, доступной текущему пользователю |

Событие отключения компонента Defender описывает наблюдённое действие.
Оно не заменяет свежий снимок всего антивирусного состояния. Событие входа
не является доказательством продолжающегося пользовательского сеанса.

## Действующий источник данных

Отчёт использует текущую регистрацию и канонический журнал, который наполняется
нативным приёмником рабочих станций. Старые таблицы workstation observations,
station summary и check findings не используются как источник текущего состояния.

В действующем профиле приёмника разрешены:

| Область | События Windows |
|---|---|
| Входы и ошибки входа | 4624, 4625 |
| Очистка журнала | 1102 |
| Локальные группы | 4732, 4733 |
| Создание задания | 4698 |
| Службы | 7036, 7040, 7045 |
| Изменения Defender | 5001, 5010, 5012 |

Конкретное назначение агента может разрешать часть этого набора. Процессы 4688,
USB и свежие снимки Defender требуют отдельного поддерживаемого пути сбора;
отсутствие их записей здесь не означает отсутствия активности на компьютере.

## Правила интерфейса и реализации

- Основной список — таблица полезных свойств, без плиток произвольных итогов.
- Состояние назначения сбора отмечено точкой рядом с именем станции;
  расшифровка доступна в подсказке и средствам чтения с экрана.
- Подробности станции и записи открываются на всю ширину; длинные сведения
  не помещаются в боковую карточку.
- Состояние, наблюдённое событие и подтверждённая проблема показываются отдельно.
- Цвет критичности сопровождается текстом и опирается на серверную проблему.
- Недоступность данных объясняется в соответствующем месте: не назначен источник,
  нет доступа к журналу или тип данных не входит в действующий профиль.
- Параметры навигации не передаются в API как фильтры. Источник, период,
  размер страницы и контекст возврата сохраняются явно.
- Права на станции, журнал, проблемы и точные доказательства остаются раздельными.
  Ни переход, ни счётчик не расширяет область доступа.

Открытие отчёта выполняет чтение. Назначение модулей и изменение политики сбора
производятся штатными средствами администрирования.
