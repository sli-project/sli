# Журнал событий

[English version](../../en/screens/event-journal.md) · [Рабочие экраны](../user-guide.md)

Откройте **Журнал событий** по пути `/app/report/events.journal`, чтобы
найти и проверить отдельные собранные события.

1. Выберите доступные период и домен. Укажите категорию, например **Входы**,
   **Учётные записи**, **Группы и права** или **Аудит**. Ищите по учётной
   записи, компьютеру, адресу или событию. Сверьте время, код, журнал и
   результат.
2. Используйте **Свернуть повторы** для компактного просмотра. Разверните
   повторы, чтобы увидеть отдельные исходные события при наличии данных.
   По ссылке на учётную запись, адрес или компьютер можно сузить поиск.
3. Откройте строку и вкладки **Сведения** и **Исходное событие**. Перед выводом
   по коду события проверьте источник, журнал и номер записи. Перейдите
   в полную карточку для просмотра сохранённого доказательства, если
   позволяет доступ.
4. При переходе из [Проблем](problems.md) сверяйте выбранную находку и
   период. У исходного содержимого и сводных данных события могут быть
   разные сроки хранения.
