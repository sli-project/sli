# Рабочие экраны

[English version](../en/user-guide.md) · [Оглавление](README.md)

Руководства описывают экраны беты на исходном коммите `a164f00`. Пути
указаны относительно HTTPS-адреса вашего сервера SLI. Состав данных, карточек
и действий зависит от действующих прав пользователя и доступных данных
источников.

| Экран | Путь |
| --- | --- |
| [Главная](screens/home.md) | `/app/` |
| [Проблемы](screens/problems.md) | `/app/report/security.problems` |
| [Журнал событий](screens/event-journal.md) | `/app/report/events.journal` |
| [Изменения в домене](screens/domain-changes.md) | `/app/report/security.events.chains` |
| [Состояние AD](screens/ad-state.md) | `/app/report/ad.infrastructure` |
| [Пользователи](screens/users.md) | `/app/report/ad.users.v2` |
| [Компьютеры](screens/computers.md) | `/app/report/ad.computers.v6` |
| [Групповые политики](screens/gpo.md) | `/app/report/ad.gpo.v2` |

[Каталог обнаружений](detections.md) объясняет, как разобрать десять
наблюдаемых признаков по сохранённым данным. Права и исправность источников
описаны в [администрировании](admin.md) и
[устранении неполадок](troubleshooting.md).
