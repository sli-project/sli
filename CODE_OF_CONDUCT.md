# Code of conduct

SLI is built by people who investigate security incidents and run
infrastructure. We expect the same professionalism from everyone who takes
part in issues, pull requests and discussions.

- Be respectful. Criticise code and decisions, not people.
- Assume good intent and ask before concluding.
- Keep discussions on topic and in public channels of the project.
- Never post real logs, account names, hosts, IP addresses, SIDs, credentials
  or screenshots with real data — yours or anyone else's.
- Harassment, discrimination and personal attacks are not tolerated.

Maintainers may edit or remove contributions and block participants who do not
follow these rules. Report a problem privately to the maintainers through the
repository's private channels (see `SECURITY.md`); reports are handled
confidentially.
