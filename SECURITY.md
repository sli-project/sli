# Security policy

To report a vulnerability privately, open the repository’s **Security** tab,
select **Advisories**, then choose **Report a vulnerability**. Include the
affected version, reproduction steps, and impact. Keep vulnerability details,
credentials, and incident evidence out of public issues and pull requests.

If a secret is committed, stop distribution immediately, revoke or rotate the
credential outside GitHub, preserve the incident facts without copying the
secret, and remove it from every publishable revision before resuming work.
Making the repository private does not make committed secrets safe.

Operational contacts are maintained through GitHub organization membership; no
personal email address is published in this repository.
